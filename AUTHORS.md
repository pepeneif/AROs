# Authors

## Concept and authorship

**Agent Run Organizations (AROs)** — the market-native governance framework, its organizational model
(Managing / Challenger / Mirror Agents, the client-credential token, bonding-curve governance) and its
whitepaper — is an original concept by **Jose Neif**.

The git history of this repository is the primary record of authorship: it dates the concept and its
evolution from the first commit. Please preserve it.

## Prior work (context)

Jose Neif's background includes work on decentralized governance tooling in the Solana ecosystem. This
is provided as context for the author's domain experience; it does not imply any transfer of code or
intellectual property into AROs, which is 100% original work.
